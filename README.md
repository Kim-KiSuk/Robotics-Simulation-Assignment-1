# Ant 보행 일반화: 지형과 마찰 변화에 대응하기

평지에서 학습한 Ant가 새로운 지형과 마찰 조건에서도 안정적으로 전진하도록
환경과 학습 방식을 보완하는 프로젝트입니다. 기본 PPO에서 출발해 **학습 지형을
다양하게 만들고, 지면 마찰을 바꿔 학습한 뒤, 보상과 관측의 보완 방향을 검토**했습니다.

현재 저장소에는 A·B·C의 학습 모델과 평가 결과가 있습니다. **R·H·HR은 구현과
기능 검증을 마친 후속 실험이며, 본 학습 결과는 아직 포함되어 있지 않습니다.**

| 실험 | 보완하려는 부분 | 핵심 변경 | 진행 상태 |
|---|---|---|---|
| A · 기본 모델 | 비교할 기준 확보 | 원본 평지에서 PPO 학습 | 학습·평지 평가 완료 |
| B · 험지 모델 | 지형 높낮이 변화 | 여러 지형에서 학습, 높이 관측·낙상 판정 보완 | 학습·험지 평가 완료 |
| C · 마찰 변화 모델 | 특정 마찰에 대한 의존 | B의 지형에 구역별 마찰 무작위화 추가 | 학습·험지 평가 완료 |
| R · Reward | 위험한 자세와 급격한 행동 | B에 안정성을 고려한 보상 추가 | 구현·기능 검증 완료 |
| H · History | 한 시점 관측의 한계 | B에 최근 4개 시점의 관측 이력 추가 | 구현·기능 검증 완료 |
| HR · History + Reward | 관측과 보상의 함께 작용하는 효과 | B에 두 변경을 함께 적용 | 구현·기능 검증 완료 |

## 1. 출발점: 평지에서 기준 모델 만들기 — A

원본 `Isaac-Ant-v0`의 평면에서 PPO를 1000 iterations 학습했습니다. 기존의
전진·생존·자세 보상과 행동·에너지 등의 페널티를 유지해 이후 실험의 출발점을 만들었습니다.

기본 마찰의 평지에서 평균 보상은 **144.57 ± 25.75**였습니다. 같은 평지에서도
저마찰에서는 123.01, 고마찰에서는 130.27로 평균 보상이 낮아졌습니다.
이는 지면 조건의 변화에 대한 대응을 살펴볼 필요가 있다는 출발점입니다.

이 수치는 평지 평가 결과입니다. 아래 B/C의 험지 결과와는 평가 환경이 다르므로
보상 크기로 모델의 순위를 매기지 않습니다. A를 동일한 험지에서 평가하는 비교는
후속 과제로 남아 있습니다.

[A 체크포인트](artifacts/checkpoints/A/model_999.pt) · [A 보행 녹화](artifacts/videos/A_play.mp4)

## 2. 지형 형상에 대응하도록 보완 — B

평면을 요철·파도·경사·평지가 섞인 학습 지형으로 바꿨습니다. 평지에서만 얻는
경험을 넓히면서, 높낮이가 달라져도 관측과 실패 판정이 같은 의미를 갖도록 보완했습니다.

- **학습 경험 확대:** 528×528m 지도에 여러 지형을 배치해 높낮이가 다른 지면을 경험하도록 했습니다.
- **높이 해석 수정:** 몸통의 절대 높이 대신 바로 아래 지면과의 높이 차이를 관측합니다.
  경사면 위에 있다는 이유만으로 몸이 높게 떠 있다고 해석하지 않도록 했습니다.
- **낙상 판정 보완:** 지면과 몸통 사이의 높이가 0.31m보다 낮아지면 종료합니다.
- **시작 위치와 충돌 처리 보완:** 지형 높이에 맞춰 로봇을 배치하고, 큰 지형의 충돌 영역을
  나눠 물리 시뮬레이션에서 밟고 이동할 수 있게 구성했습니다.

보상과 PPO 설정은 원본을 유지했습니다. 관측은 여전히 60차원이며,
높이 항목의 의미만 지면 기준으로 바뀌었습니다. 마찰은 1.0으로 고정했습니다.
A와 B는 각각 처음부터 같은 1000-iteration 예산으로 학습했습니다.

현재 B는 아래 B/C 비교에서 기본·고마찰 조건의 평균 보상이 더 높은 모델입니다.

## 3. 마찰 조건에도 대응하도록 보완 — C

지형을 다양하게 만들어도 마찰이 하나로 고정되어 있으면, 다른 바닥 재질에서
보행 성능이 달라질 수 있습니다. 이를 확인하기 위해 B의 지형과 보상·관측을
유지하면서 **지면의 마찰만 구역별로 다르게 설정**해 학습했습니다.

지면의 정적 마찰은 0.4~1.5 범위에서 뽑고, 동적 마찰은 해당 정적 마찰의
75~100%로 설정했습니다. 기본 지도는 16개 구역으로 나뉘며, 마찰 배치는
한 번의 학습 동안 고정됩니다. 에피소드가 끝날 때마다 다시 뽑는 방식은 아닙니다.

C도 처음부터 1000 iterations 학습했습니다. 여러 마찰 조건을 경험하면 새 바닥에
잘 대응할 것이라는 가설이었지만, **현재 측정 결과에서는 B보다 나아지지 않았습니다.**

[C 체크포인트](artifacts/checkpoints/C/model_999.pt) · [C 보행 녹화](artifacts/videos/C_play.mp4)

### 같은 조건에서 비교한 B와 C

학습에 사용하지 않은 지형 seed 2001/2002에서 각각 100개 환경을 평가했습니다.
초기 상태 seed는 24이며, 각 환경의 첫 에피소드를 최대 16초까지 측정했습니다.
아래 보상은 마찰별 200개 에피소드를 합친 **평균 ± 모집단 표준편차**입니다.

| 지면 정적 / 동적 마찰 | B 보상 | C 보상 | B 평균 생존 steps | C 평균 생존 steps |
|---|---:|---:|---:|---:|
| 기본 1.0 / 1.0 | 98.09 ± 28.88 | 90.55 ± 26.24 | 893.56 | 889.48 |
| 낮음 0.4 / 0.3 | 104.13 ± 23.93 | 103.62 ± 22.12 | 920.71 | 921.24 |
| 높음 1.5 / 1.2 | 96.33 ± 26.53 | 83.08 ± 27.28 | 904.47 | 865.30 |

![B와 C의 마찰별 보상 비교](results/bc_comparison.png)

기본·고마찰에서는 B가 더 높고, 저마찰에서는 차이가 작았습니다. 마찰 무작위화의
효과가 이번 설정에서는 확인되지 않았다는 결과입니다. 마찰 범위와 구역 배치가
학습을 어렵게 했는지, 다른 학습 seed에서도 같은 경향인지 추가 확인이 필요합니다.
이 원인들은 현재 데이터만으로 확정할 수 없습니다.

표의 마찰은 지면 재질 설정값이며 실제 접촉에는 로봇 발의 재질도 함께 작용합니다.
평균 steps는 에피소드 길이이며 생존율과 다릅니다. 학습 seed가 하나이고 평가 지도도
두 개이므로 일반화 전반의 우열을 단정하지 않습니다. 이 지도들은 이후 방법 선택에
사용하는 validation 조건으로 취급합니다.

## 4. 다음 보완: 보상과 관측을 각각 개선 — R · H · HR

B를 기준으로 **무엇을 좋은 행동으로 평가하는지**, **정책이 어떤 정보를 보고
행동하는지**를 각각 바꾸는 실험을 준비했습니다. 세 실험 모두 PPO를 사용합니다.
B의 가중치를 이어 학습하는 방식이 아니라, 같은 학습량으로 새로 학습해 비교하도록
구성했습니다.

### R — Reward: 안정적인 보행을 보상에 반영

기존 전진 보상을 유지하면서 위험 상태와 거친 동작에 다음 페널티를 추가했습니다.

- **실패 종료 시 -5:** 넘어짐 등의 실패를 학습 신호에 직접 반영합니다.
  시간 제한까지 도달한 경우에는 이 페널티를 주지 않습니다.
- **몸통이 지면에 가까워질 때 감점:** 0.40m 아래부터 위험도를 반영해
  낙상 기준 0.31m에 도달하기 전부터 위험한 자세를 줄이도록 유도합니다.
- **행동이 급격히 바뀔 때 작은 감점:** 관절에 주는 힘 명령의 급격한 변화를 줄이도록 유도합니다.

R의 관측은 B와 같은 60차원입니다. 기존 전진 보상에 속도 상한을 추가하지 않았습니다.
페널티가 너무 강하면 이동 속도나 지형 대응을 떨어뜨릴 수 있으므로, 실제로 더 잘
걷는지는 같은 조건의 보상·생존율·이동 거리를 함께 보고 판단해야 합니다.

### H — History: 최근 상태 변화를 함께 관측

기존 정책은 현재의 속도·자세·관절 상태·힘·이전 행동 등을 한 시점의 입력으로
받습니다. H는 **현재 시점을 포함한 최근 4개 시점의 관측**을 함께 제공합니다.

예를 들어 현재 속도만 보는 것보다, 최근 명령에 따라 속도와 몸통 자세가 어떻게
변했는지를 보면 바닥에서의 반응을 판단하는 데 도움이 될 수 있습니다.
마찰계수의 정답을 알려주는 대신 이런 변화를 정책이 활용하도록 하는 가설입니다.

입력은 60차원에서 240차원으로 늘어나며, 60Hz 제어에서 약 0.05초 전까지의
정보를 포함합니다. 보상은 B와 같습니다. 입력층 크기도 커지므로 기존 B/C 모델을
그대로 불러올 수 없고, 평가할 때에도 동일한 관측 이력 처리가 필요합니다.

### HR — History + Reward: 두 보완을 함께 적용

HR은 R의 보상 변경과 H의 관측 이력을 동시에 사용합니다. R·H를 따로 두는 이유는
효과가 보상에서 왔는지, 관측에서 왔는지, 두 방법을 함께 쓸 때 달라지는지
구분하기 위해서입니다. **R → H → HR 순서로 성능이 좋아진다는 의미는 아닙니다.**

| 비교 | 확인하려는 질문 |
|---|---|
| B vs R | 보상 변경이 낙상을 줄이면서 전진 성능을 유지하는가? |
| B vs H | 최근 관측 이력이 다른 지면 조건에 대응하는 데 도움이 되는가? |
| R/H vs HR | 두 변경을 함께 적용했을 때 추가 효과나 부작용이 있는가? |

세 실험은 설정과 관측 초기화 검사를 마쳤고, HR은 작은 환경에서 PPO 업데이트와
평가 연결까지 확인했습니다. **아직 성능 향상을 보여주는 본 학습·비교 결과는 없습니다.**

## 5. 보완 효과를 공정하게 판단하도록 평가도 수정

학습 보상을 바꾸면 TensorBoard의 보상 크기만으로 모델을 비교하기 어렵습니다.
새 평가기는 모든 모델을 **원본의 동일한 7개 보상 항목**으로 평가하고, 생존율과
이동 거리·속도를 함께 기록합니다. 종료된 로봇이 자동으로 시작점으로 돌아가기
직전의 위치를 사용하므로, reset 이동이 보행 거리로 섞이지 않습니다.

기존 B를 기본 마찰·지형 seed 2001·100개 환경에서 재평가했을 때 보상과 steps는
기존 결과와 소수점 6자리까지 일치했습니다. 이 **한 조건**의 추가 지표는 다음과 같습니다.

| 지표 | B의 재평가 결과 |
|---|---:|
| 16초까지 실패 없이 생존 | 92 / 100 |
| 평균 목표 방향 이동 거리 | 95.49m |
| 에피소드별 목표 방향 평균 속도의 평균 | 6.05m/s |
| 지면 ray가 지도를 벗어난 에피소드 | 0 / 100 |

다음 실험에서는 R과 H를 먼저 B와 비교하고, 효과를 확인한 뒤 HR을 평가합니다.
방법 선택에 쓰지 않은 지도와 새로운 지형 형상·강도, 여러 학습 seed로 평가를
넓혀갈 계획입니다. 같은 지형 생성기의 seed만 바꾼 결과가 모든 새로운 지형으로의
일반화를 보장하지는 않습니다.
