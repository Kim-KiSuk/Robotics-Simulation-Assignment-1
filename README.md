# Ant: 다섯 지형 혼합 학습 → 높이 관측 → 안정성 추가 학습

**학습에 사용하지 않은 지형과 마찰 조건에서도, Ant가 제한 시간 16초 안에 멀리 전진하도록 만드는 실험**입니다. 수업의 `Isaac-Ant-v0`를 출발점으로 삼았습니다. 학습용 환경 5개와 평가용 환경 1개를 나눈 시점부터 환경 설계, 관측 보완, 추가 학습의 이유와 결과를 정리합니다.

| 모델 | 해결하려는 문제와 변경 | 관측 | 학습 | 체크포인트 |
|---|---|---:|---|---|
| **SixMix** | 한 바닥에만 적응하지 않도록 다섯 지형 구성과 마찰 조건을 한 정책으로 학습 | 60D | 처음부터 4000회 | [model_3999.pt](artifacts/checkpoints/SixMix/model_3999.pt) |
| **HeightScan** | 앞쪽 높낮이를 알 수 있도록 주변 지면 높이 63개 추가 | 123D | 처음부터 4000회 | [model_3999.pt](artifacts/checkpoints/HeightScan/model_3999.pt) |
| **Stability** | 남아 있는 조기 종료를 줄이려 지형 범위 확대와 위험 감점을 적용 | 123D | HeightScan에서 500회 추가 | [model_499.pt](artifacts/checkpoints/Stability/model_499.pt) |

**최신 Stability 실험은 성능 향상이 확인되지 않았습니다.** 변경의 의도와 실제 결과를 구분하며, 이전 HeightScan 모델도 함께 보존합니다. 입력·학습 예산·부모 모델은 [모델 목록](artifacts/checkpoints/manifest.json)에 기록했습니다.

## 1. 왜 학습용 5개와 평가용 1개로 나눴는가

특정 지형 하나에서만 잘 걷는 정책을 피하려고 서로 다른 보행 문제를 T1~T5로 나눴습니다. 평가용 E1은 학습에 쓰지 않은 배치와 마찰 조합으로 남겼습니다.

| 구성 | 경험하게 할 지형 | 지면 정적 / 동적 마찰 | 개별 terrain seed | 선정 이유 |
|---|---|---:|---:|---|
| T1 | 작은 랜덤 요철 | 1.0 / 1.0 | 1101 | 불규칙한 지면에서 자세 유지 |
| T2 | 파도: 반복되는 높낮이 | 0.8 / 0.6 | 1102 | 오르내림에 맞춘 보행 |
| T3 | 경사·역경사 | 1.2 / 1.0 | 1103 | 연속적인 기울기 변화 대응 |
| T4 | 높이가 다른 사각 블록 | 0.6 / 0.45 | 1104 | 과제 예시 설명에 맞춘 발 디딤 연습 |
| T5 | 계단 상하·random grid·경사 상하 | 1.4 / 1.1 | 1105 | IsaacLab의 다섯 생성기를 함께 경험 |
| E1 | 위 구성의 새 배치 | 0.9 / 0.75 | 9117 | 같은 생성 분포의 미사용 조건 확인 |

실제 학습에는 **`Isaac-Ant-Six-TrainMix-v0` 하나**를 사용합니다. seed **1100**으로 T1~T5의 생성 구성을 각각 20% 확률로 선택한 혼합 지도를 만들고, 여러 로봇이 한 정책으로 경험을 수집합니다. 다섯 개의 별도 모델을 합치는 방식은 아닙니다.

마찰은 타일 종류에 연결되어 실행 중 고정됩니다. 매 에피소드 재추첨이나 연속 범위에서의 마찰 무작위화는 아닙니다. 지형과 마찰을 함께 바꿨으므로 두 효과를 따로 분리한 실험도 아닙니다. 실제 접촉에는 로봇 재질과 `average` 결합 규칙이 함께 적용됩니다.

![T1~T5와 E1 지형 표본](docs/ant_six_envs/assets/six_terrains.png)

실제 생성 메시의 CPU 시각화이며 세로를 4배 확대했습니다. 평지 전용 타일은 없지만 학습 지형에는 중앙 플랫폼과 국소 평탄 구간이 있습니다. T4는 사용자가 설명한 “높이가 다른 사각 블록”을 기준으로 만들었으며 과제 이미지의 정확한 복제는 아닙니다. [전체 수치·seed·파일 경로](docs/ENVIRONMENTS.md)

## 2. 앞쪽 지형을 관측하도록 보완

SixMix의 60차원 입력에는 자세·속도·관절 상태 등이 있지만 주변 높낮이는 없습니다. 몸 아래 한 점의 지면 높이는 몸통 높이 관측과 낙상 판정에만 사용합니다.

HeightScan은 **9×7 지점의 상대 지면 높이 63개**를 더해 입력을 **123차원**으로 늘렸습니다. 몸통 방향을 기준으로 앞 1.8m, 뒤 0.6m, 좌우 0.9m를 0.3m 간격으로 읽습니다. 블록이나 경사를 만나기 전에 정책이 높낮이를 활용할 수 있도록 한 변경입니다.

학습 지형·마찰·원본 7개 보상·8개 관절 effort 행동·PPO 설정은 SixMix와 같습니다. 입력층 크기가 달라 처음부터 학습했습니다. 이 센서는 카메라가 아니라 **시뮬레이터 메시를 읽는 이상적인 높이 센서**입니다. 실제 센서의 노이즈나 가림에 대한 성능은 검증하지 않았습니다.

두 모델 모두 1024개 환경 × 32 step × 4000회, 총 **131,072,000 transition**으로 학습했습니다. 혼합 지형에서 4096개 로봇은 RTX 2080 8GB의 PhysX 메모리 할당에 실패하여 병렬 수를 줄였습니다. 원본 Baseline의 총 경험 수와 같지만 배치 크기와 업데이트 횟수는 다릅니다.

## 3. 평가 지형을 E1에서 블록 포함 E3로 확장

| 평가맵 | 변경 이유 | 구성 | terrain seed |
|---|---|---|---:|
| E1 | 학습과 다른 배치·마찰에서 확인 | T1~T5 혼합 | 9117 |
| E2 | 연속 높낮이가 뚜렷한 지형에서 확인 | 요철·파도·경사, 중앙 플랫폼 제거 | 9217 |
| E3 | 블록 대응도 함께 확인 | 블록 35%, 요철 25%, 파도 20%, 경사 상하 20% | 9317 |

![블록 포함 E3 지형 표본](docs/ant_six_envs/assets/blocks_eval/preview.png)

E3는 8m 타일 40×40개, 320×320m 지도입니다. 블록 폭은 0.8m, 높이 변동 크기는 3~12cm이며 이웃 칸의 높이차는 최대 약 24cm입니다. 평지 전용 타일·중앙 플랫폼·평탄 테두리는 없지만 블록 윗면 같은 국소 수평면은 있습니다. 그림은 CPU 메시이며 세로를 3배 확대했습니다.

평가 지면 마찰은 0.9 / 0.75, 실행 seed는 **24**, 환경 수는 **100**으로 맞춥니다. 실행 seed와 terrain seed는 별개입니다. 반복 개선에 사용한 E1~E3는 이제 검증용입니다. 최종 일반화 주장을 위해 별도의 미사용 seed와 마찰 조건을 남겨야 합니다.

## 4. 조기 종료를 줄이기 위한 Stability 추가 학습

높이 관측을 넣어도 시간 제한 전에 끝나는 에피소드가 남았습니다. 이미 학습한 보행을 출발점으로 아래 변경을 함께 적용했습니다.

- **지형:** 기존 생성 범위 70% + 확대 범위 30%, 새 terrain seed **1200**. 더 큰 높낮이·계단·기울기를 경험하게 했습니다.
- **학습 보상:** 원본 7개 항을 유지하고 실패 사건당 **−5**, 몸통 높이가 지면 대비 0.40m 아래로 낮아질 때 연속 위험 감점을 추가했습니다. 정상 timeout에는 실패 감점을 주지 않습니다.
- **학습 방식:** HeightScan 가중치를 불러오고 optimizer·반복 카운터는 초기화했습니다. 학습률 **1e-5 고정**, entropy **0.001**, 초기 행동 표준편차 하한 **0.02**로 500회 추가 학습했습니다.

관측은 123차원으로 유지합니다. 평가에는 Stability 학습 보상이 아닌 **원본 Ant의 7개 보상**을 사용하는 E3 HeightScan Task를 씁니다. 지형과 보상을 함께 바꾼 실험이므로 각각의 효과는 분리할 수 없습니다. [변경 코드와 상속 관계](docs/ENVIRONMENTS.md#코드와-상속-경로)

## 5. 결과: 추가 학습이 항상 개선을 뜻하지는 않았다

`play_one_episode.py`, seed 24, 환경 100개, 각 환경의 첫 에피소드가 기준입니다. **100/100 완료는 100개 모두 생존했다는 뜻이 아닙니다.**

| E3 결과 | HeightScan 부모 모델 재평가 기록¹ | Stability 500회 추가 학습² |
|---|---:|---:|
| 원본 누적 보상 mean ± std | 42.608490 ± 25.110875 | 41.514310 ± 24.873176 |
| 목표까지 거리 감소 mean ± std (m) | 39.384821 ± 23.634968 | 38.242646 ± 23.541899 |
| 에피소드 길이 mean ± std (step) | 703.33 ± 366.864963 | 696.62 ± 366.142917 |
| 실패 없이 16초 도달 | 60% | 59% |

¹ 추가 학습 준비 당시 남긴 에피소드별 JSON입니다. ² 사용자가 제공한 실행 명령과 터미널 출력입니다. 부모 모델은 headless 기록, 최신 평가는 GUI·영상 실행이므로 완전히 일치하는 실행 비교로 단정하지 않습니다. 이번 업로드 중 시뮬레이션 평가를 새로 돌리지는 않았습니다.

현재 기록에서는 전진 거리와 생존 비율이 개선되지 않았습니다. Stability를 최종 우수 모델로 선택할 근거가 없으며, 다음 비교에서는 같은 실행 모드로 두 체크포인트를 평가하고 지형별 실패를 나눠 봐야 합니다. 학습 위험 감점이 평가 점수에 직접 합산된 결과는 아닙니다.

초기 E2에서 SixMix의 보상은 **54.428906 ± 29.085658**, 평지 Baseline은 **14.283684 ± 12.772225**로 보고되었습니다. 다만 E3 HeightScan의 초기 보고값 **53.930177**과 위 재평가값 **42.608490** 사이의 차이는 아직 설명되지 않았습니다. 유리한 값만 골라 결과로 제시하지 않도록 [전체 결과·원자료·해석의 한계](results/SIX_RESULTS.md)에 구분했습니다.
