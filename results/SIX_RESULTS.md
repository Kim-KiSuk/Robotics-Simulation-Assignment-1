# Six 환경 이후의 결과와 해석

평가 기준은 `play_one_episode.py`, 실행 seed **24**, 환경 **100개**, 각 환경의 첫 에피소드입니다. 평가 보상은 원본 Ant의 7개 항입니다. 이 문서는 기존 기록을 정리한 것이며 이번 업로드 중 새 시뮬레이션 평가를 실행하지 않았습니다.

## 최신 E3: HeightScan 부모와 Stability

E3의 기본 terrain seed는 9317, 지면 정적/동적 마찰은 0.9/0.75, 관측은 123D입니다. 같은 `Isaac-Ant-Six-Eval-Blocks-HeightScan-v0`로 평가했습니다.

부모 모델은 [기존 에피소드별 JSON](validation/stability_pretraining/parent_control.json)과 체크포인트 hash가 있습니다. 최신 Stability는 사용자가 제공한 [명령·구조화 기록](stability/user_reported_result.json)과 [터미널 출력](stability/user_reported_output.txt)입니다. 최신 출력에는 에피소드별 JSON이 없으며 모델 hash는 업로드할 파일에서 확인한 값입니다. 부모 기록은 headless, 사용자 명령은 GUI·영상 실행으로 실행 모드가 다릅니다.

Stability의 추가 학습은 더 넓은 지형 범위와 실패·낮은 몸 높이 감점을 통해 조기 종료를 줄이려는 시도였습니다. 기록된 평균 전진량은 약 1.14m 줄었고 timeout 비율도 1%p 낮아졌습니다. **개선이 입증되지 않았으며 이 차이를 유의한 성능 저하나 특정 보상 항의 효과로 단정할 수도 없습니다.** 원본 보상으로 평가하므로 추가한 학습 감점 자체가 이 점수에 합산된 것은 아닙니다.

59%는 100개 중 59개가 실패 없이 16초에 도달했다는 뜻입니다. 나머지 41개의 종료를 모두 실제 뒤집힘으로 단정할 수는 없습니다. 상대 몸 높이가 기준 아래로 내려가도 종료됩니다. 누락 0은 해당 진단에서 누락이 관측되지 않았다는 뜻이며 모든 물리 동작의 정확성을 보장하지 않습니다.

## 어떤 결론을 낼 수 있는가

- 서로 다른 맵의 보상은 난이도가 달라 직접 순위로 비교하지 않습니다.
- HeightScan과 평지 Baseline은 관측뿐 아니라 학습 환경도 다릅니다. **센서의 효과**는 SixMix와 HeightScan을 같은 E3에서 비교해야 판단할 수 있습니다.
- Stability는 보상과 학습 지형을 동시에 변경했습니다. 각각의 효과를 밝히려면 한 항목만 바꾼 비교가 필요합니다.
- 표의 std는 환경 100개 에피소드의 산포입니다. 학습 seed를 여러 번 반복한 모델 간 변동성이 아닙니다.
- `Target progress`는 목표까지 거리의 감소, `Forward displacement`는 world X 순변위입니다. 이동 경로의 총 길이와 다릅니다.
- E1~E3를 보고 방법을 수정했으므로 최종 미사용 평가 조건으로 계속 부르면 안 됩니다. 새로운 seed·마찰 조합을 마지막 비교용으로 남깁니다.

다음 검증은 공개한 SixMix·HeightScan·Stability를 같은 headless 명령과 E3에서 다시 비교하고 에피소드별 JSON을 저장하는 것입니다. 이후 미사용 조건에서 최종 비교합니다. [실행 명령](../docs/REPRODUCE.md)
