# Ant 보행 일반화: 처음 보는 지형에서도 멀리 걷기

평지에서 학습한 `Isaac-Ant-v0`를 기준으로, **학습 지형·마찰을 다양하게 만들고 주변 지면 높이를 관측에 추가**한 프로젝트입니다. 목표는 제한 시간 16초 안에 처음 보는 지형에서도 전진하는 것입니다. 평가는 원본 Ant 보상을 사용합니다.

이번 업로드는 **블록 포함 E3 평가맵과 123차원 높이 관측 모델의 학습·평가 기록까지**입니다. 이후의 Stability 추가 학습 변경은 포함하지 않습니다.

## 무엇을 보완했는가

| 단계 | 해결하려는 문제 | 적용한 방법 | 이 저장소에 있는 결과물 |
|---|---|---|---|
| A · 평지 Baseline | 비교 기준 필요 | 원본 평지·관측·보상·PPO 학습 | 최종 모델, 학습 로그, 평가 결과 |
| B / C · 초기 험지 실험 | 지형·마찰 변화에 대한 취약성 | 지면 기준 높이, 험지 학습, C의 구역별 마찰 변화 | 최종 모델과 동일 조건 비교 |
| R / H / HR · 초기 보상·관측 실험 | 낙상과 단일 시점 관측의 한계 | R: 학습 보상 / H: 4시점 이력 / HR: 둘 모두 | 구현, 당시 검증 기록, B/R의 Varied 평가 원자료 |
| SixMix · 다섯 학습 구성 혼합 | 경험하는 지형의 폭 확대 | 요철·파도·경사·블록·계단 혼합, 종류별 마찰 | 60차원 최종 모델, 4000회 학습 로그, E1/E2 결과 |
| HeightScan · 주변 높이 관측 | 앞쪽 높낮이를 정책에 알려주기 | SixMix의 60차원 상태에 높이 63개 추가 | 123차원 최종 모델, 4000회 학습 로그, E3 평가 출력 기록 |

R/H/HR의 H는 **관측 이력(History)**이고, 이번 **HeightScan은 주변 지면 높이**입니다. 서로 다른 방법입니다. R/H/HR의 완성 체크포인트는 이번 묶음에 없으며, 과거 문서의 진행 상태는 작성 당시 기록으로 보존했습니다.

## 1. 하나의 정책이 여러 바닥을 경험하도록 변경

학습용 다섯 구성을 각각 따로 확인할 수 있게 만들고, 실제 학습에는 `TrainMix`로 함께 사용했습니다. 여러 로봇이 **하나의 정책**으로 경험을 수집합니다.

| 학습 구성 | 지형 | 지면 정적 / 동적 마찰 |
|---|---|---:|
| T1 | 작은 랜덤 요철 | 1.0 / 1.0 |
| T2 | 2파·4파의 반복 높낮이 | 0.8 / 0.6 |
| T3 | 경사·역경사 | 1.2 / 1.0 |
| T4 | 높이가 다른 사각 블록 | 0.6 / 0.45 |
| T5 | 계단 상하·random grid·경사 상하 | 1.4 / 1.1 |

각 구성의 타일 선택 확률은 20%입니다. 마찰은 지형 종류와 연결되며 실행 중 고정됩니다. 매 에피소드마다 마찰이나 메시를 다시 만드는 방식은 아닙니다. 실제 접촉 마찰은 로봇 재질과 `average` 결합 규칙의 영향도 받습니다.

평지 전용 타일은 넣지 않았지만 학습 맵에는 출발용 플랫폼과 국소 평탄 구간이 있습니다. 지형과 마찰을 함께 바꾼 설계이므로 둘의 효과를 따로 분리한 실험은 아닙니다.

![학습용 다섯 구성과 E1 지형 표본](docs/ant_six_envs/assets/six_terrains.png)

위 그림은 실제 생성 메시의 CPU 시각화입니다. 높이를 보기 쉽게 세로 비율을 4배로 늘렸으며 보행 영상은 아닙니다.

## 2. 앞쪽 지형을 알 수 있도록 관측 보완

기존 60차원 입력에는 몸통 자세·속도·관절 상태 등이 있지만, 주변 높낮이를 미리 읽는 정보는 없었습니다. 몸 아래 한 점을 읽는 센서는 몸 높이와 낙상 기준에만 사용했습니다.

HeightScan은 **9×7 지점의 상대 지면 높이 63개**를 추가합니다. 몸통 기준 앞쪽 1.8m, 뒤쪽 0.6m, 좌우 0.9m 범위를 0.3m 간격으로 읽고 몸통의 yaw 방향에 맞춰 회전합니다. 입력은 **60 + 63 = 123차원**입니다.

카메라 영상이 아닌 시뮬레이터 메시의 이상적인 높이 측정입니다. 실제 센서의 가림·노이즈까지 검증한 것은 아닙니다. 60차원 모델과 입력층이 달라 기존 가중치를 그대로 불러오지 않고 처음부터 학습했습니다.

HeightScan과 SixMix는 학습 지형·마찰·원본 7개 보상·8개 effort 행동·PPO 설정을 공유합니다. 관측만 보완한 효과를 확인하려면 **두 모델을 같은 E3에서 직접 비교**해야 합니다. 현재 공개된 E3 비교는 HeightScan과 평지 Baseline입니다.

## 3. 평가맵을 분리하고 블록 포함 맵으로 확장

| 평가맵 | 목적 | terrain seed | 특징 |
|---|---|---:|---|
| E1 | 같은 생성 분포의 새 배치·마찰 조합 | 9117 | T1~T5 혼합 |
| E2 | 더 뚜렷한 연속 높낮이 확인 | 9217 | 요철·파도·경사, 평지 전용 타일·중앙 플랫폼 없음 |
| E3 | 블록과 연속 지형을 함께 확인 | 9317 | 블록 35%, 요철 25%, 파도 20%, 경사 상하 20% |

E3는 8×8m 타일 40×40개로 만든 320×320m 지도이며 지면 마찰은 0.9 / 0.75입니다. 블록은 폭 0.8m, 높이 변동 크기 3~12cm입니다. 이웃 블록 높이차는 최대 약 24cm일 수 있습니다. **평지 전용 타일·중앙 플랫폼·평탄 테두리를 넣지 않았습니다.** 블록 윗면 등 국소 수평면은 존재합니다.

![블록 포함 E3 지형 표본](docs/ant_six_envs/assets/blocks_eval/preview.png)

E3 역시 실제 생성 메시의 CPU 그림이며 세로를 3배 확대했습니다. 확률과 실제 100개 로봇의 시작 지형 비율은 다릅니다. E3 초기 배치는 블록 36개, 요철 40개, 파도 8개, 경사 16개입니다.

## 4. 평가 결과와 해석

공식 방식은 `play_one_episode.py`, **seed 24, 환경 100개**, 각 환경의 첫 에피소드, **원본 Ant 보상**입니다. `100/100 완료`는 모든 로봇이 16초 생존했다는 뜻이 아닙니다.

| 맵 | 모델 | 누적 보상 mean ± std | 에피소드 길이 mean ± std (step) |
|---|---|---:|---:|
| E1 | SixMix | 72.007249 ± 24.702503 | 854.81 ± 254.199083 |
| E2 | 평지 Baseline | 14.283684 ± 12.772225 | 409.94 ± 339.345423 |
| E2 | SixMix | 54.428906 ± 29.085658 | 733.49 ± 328.546846 |
| E3¹ | 평지 Baseline | 9.344116 ± 8.764984 | 386.83 ± 332.840444 |
| E3¹ | HeightScan | 53.930177 ± 23.518258 | 775.28 ± 297.930330 |

| E3 추가 지표¹ | 평지 Baseline | HeightScan |
|---|---:|---:|
| 목표까지 거리 감소 mean ± std (m) | 9.585305 ± 9.210645 | 52.982837 ± 23.187748 |
| 실패 없이 16초 도달 | 17% | 61% |
| 종료 조건 발생 | 83% | 39% |
| 지면 / 스캔 누락 에피소드 | 0 / 0 | 0 / 0 |

¹ **사용자가 제공한 터미널 출력 기록**입니다. 특히 E3는 정확한 실행 명령·체크포인트 해시·에피소드 JSON이 출력과 함께 남아 있지 않아 동일 조건 재현값으로 확정하지 않았습니다. 공개한 체크포인트가 이 수치를 그대로 재현한다고 보장하지 않습니다. [전체 수치와 출처](results/SIX_RESULTS.md)를 함께 읽어 주세요.

관찰된 출력에서는 HeightScan이 더 멀리 전진하고 시간 제한까지 도달한 비율도 높았습니다. 그러나 Baseline과는 학습 지형·관측 등이 함께 달라 **센서 하나의 효과**라고 결론 내릴 수 없습니다. 종료가 39% 남아 있으며 어떤 지형에서 실패했는지는 전체 평균만으로 알 수 없습니다. 맵이 다른 E1/E2/E3의 보상도 직접 순위로 비교하지 않습니다.

Baseline의 학습 높이 입력은 world Z, 험지 평가에서는 지면 기준 높이입니다. 차원은 같아도 의미가 달라 이 비교는 완벽히 통제된 단일 변수 실험이 아닙니다. 반복 개선에 사용한 E1~E3는 검증용으로 보고, 최종 성능 주장에는 별도의 미사용 조건을 남겨야 합니다.
